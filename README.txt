COPY SOCIAL — prototipo Android con recepción desde Compartir

FUNCIONES
- Elegir una captura o imagen desde el teléfono.
- Recibir una imagen desde el menú Compartir de Android cuando la aplicación esté instalada y la plataforma comparta un archivo de imagen.
- Reconocer texto en español e inglés mediante Tesseract.js.
- Editar, copiar y guardar hasta 100 textos en el navegador.

INSTALACIÓN
1. Publica todos los archivos de esta carpeta en un sitio HTTPS.
2. Abre la dirección en Chrome para Android.
3. Menú de Chrome > Instalar aplicación / Añadir a pantalla de inicio.
4. Abre Facebook o TikTok. Si Compartir ofrece una imagen o captura compatible, selecciona COPY SOCIAL.
5. La aplicación recibe la imagen. Pulsa Reconocer texto, revisa el resultado y pulsa Copiar.

LIMITACIONES IMPORTANTES
- La recepción desde Compartir depende de lo que Facebook/TikTok y Android permitan compartir. En algunos casos la plataforma solo comparte un enlace o texto, no la imagen ni la descripción completa.
- COPY SOCIAL no entra a cuentas, no evita restricciones de acceso ni extrae texto oculto. Si no se comparte una imagen, usa una captura de pantalla y selecciónala manualmente.
- El reconocimiento OCR carga Tesseract.js desde un CDN y necesita conexión la primera vez. El texto guardado permanece en el almacenamiento local del navegador.
- Este paquete es una PWA/prototipo, no un APK firmado. Para distribuir un APK nativo haría falta empaquetar y probar el proyecto Android.
